# cfd-mesh-independence docs

This folder holds supplemental notes for the mesh-independence study.

The main narrative lives in `../README.md`. This folder is kept small on
purpose: the project is a meshing lab, not a long report, and the README is
written to be interview-ready on its own.

If you add a note here, keep it focused on one of these:

- a worked example of choosing a first-cell height for a different target y+,
- a note on how the structured mesh would be rebuilt for a cambered airfoil,
- a note on what would change for a low-Re resolved boundary layer (y+ < 1).
